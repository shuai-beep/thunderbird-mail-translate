阿里云密钥怎么拿（不需要信用卡）

  
    
    
  1. 打开 mt.console.aliyun.com，用淘宝 / 支付宝账号登录
    2. 
    
  2. 完成实名认证（选「支付宝授权」，扫一扫就过）
    3. 
    
  3. 在页面里点「开通服务」，机器翻译通用版开通即送每月 100 万字符免费额度
    4. 
    
  4. 打开 ram.console.aliyun.com/manage/ak，点「创建 AccessKey」，记下 ID 和 Secret（Secret 只显示一次）
    5. 
    
  5. 填到上面，保存后点「测试连接」
    6. 
  

  

    免费额度每月 1 号重置，不累计。超出后按 50 元/百万字符后付费，一封 1.2 万字符的邮件约 0.6 元。
  






  
腾讯云密钥怎么拿

  
    
    
  1. 打开 console.cloud.tencent.com/cam/capi，微信扫码登录
    2. 
    
  2. 完成实名认证，在「API 密钥管理」点「新建密钥」
    3. 
    
  3. 打开 console.cloud.tencent.com/tmt 点「开通服务」，否则会报 UserNotRegistered
    4. 
    
  4. 填到上面，保存后点「测试连接」
    5. 
  

  

    注意：腾讯云已于 2026-10-01 停止发放新的免费资源包，且 QPS 逐月递减，2027-10-01 起接口彻底关闭。
    现在用可能已经开始按量计费，长期建议换阿里云。
